La web se vuelve más pequeña cuando cada página está optimizada para llegar a la misma conclusión.

Extraño los sitios con habitaciones innecesarias, etiquetas raras, bromas privadas, cambios abruptos de color, rincones sin terminar y enlaces que se sienten como una nota que alguien dejó para ti.

No todas las páginas necesitan convertir, escalar o demostrar autoridad. Algunas pueden existir porque una persona quería un lugar para algo que le importaba.

Eso ya es suficientemente útil.
