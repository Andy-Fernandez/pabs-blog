## La idea

Quería una web personal, pero no una que congelara a una persona en un titular, una lista de tecnologías y una fila ordenada de trabajos terminados.

El problema no era cómo hacer otro portafolio. Era cómo hacer un lugar suficientemente amplio para software, películas, libros, cocina, pensamientos sin terminar y cualquier cosa que me importe después.

## La decisión

El sitio tiene solamente dos sistemas de contenido: **Proyectos** para las cosas que construyo intencionalmente y **Journal** para todo lo que quiero documentar o pensar.

El lenguaje visual toma cosas de fanzines, fotocopias, páginas anotadas y objetos que quedaron juntos sobre un escritorio. La imperfección no es decoración pegada encima de una plantilla de portafolio. Es parte de la idea: una web personal puede sentirse personal.

## Lo que estoy aprendiendo

La parte difícil es saber cuándo la expresión se convierte en ruido. La página de inicio puede superponer, inclinar, gritar y sorprender. Una entrada larga necesita calmarse y dejar respirar las palabras.

Este proyecto está activo. También significa que tiene permiso de cambiar conmigo.
