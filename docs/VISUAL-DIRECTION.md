# Visual Direction

## Concept

The website should feel like a personal digital fanzine: Spider-Punk energy,
photocopied print, newspaper collage, and DIY editorial composition.

The personality should be expressive without making projects or long-form Journal
entries difficult to explore and read.

## Palette

- Paper: `#FFFFFF`
- Ink: `#000000`
- Newspaper gray: `#1A1A1A`

Black and white provide the main visual contrast. A new accent color should only be
introduced when it communicates something useful, such as content type, focus, or
an important action.

## Typography

- Use a bold sans-serif display face for major titles.
- Use a typewriter or monospace face for metadata and selected details.
- Use a highly readable text face for Journal and project bodies.
- Use ransom-note or mixed-letter treatments sparingly, primarily for short
  display moments rather than navigation or paragraphs.

Typography, spacing, and content should remain the main visual elements.

## Graphic Language

- halftone or photocopy textures
- sharp, diagonal, clipped, or torn-looking edges
- thick black rules and imperfect dividers
- layered images, labels, tape, and sticker-like elements
- high-contrast project and personal photography
- occasional rotated elements that do not disrupt reading order

Prefer CSS treatments and optimized raster textures. Do not reproduce the attached
HTML example literally; it is inspiration rather than production code.

## Interaction

- Keep transitions brief and intentional.
- Hover and focus states can invert black and white or shift an element slightly.
- Avoid constant movement around reading content.
- Respect `prefers-reduced-motion`.
- Preserve keyboard navigation and clearly visible focus states.

## Layout Rules

- The homepage can use more collage and overlap than inner pages.
- Journal bodies should use a stable, narrow reading column.
- Project pages can be more visual but must still tell a clear story.
- Decorative layers must never cover links, controls, or meaningful text.
- Mobile layouts should simplify overlaps instead of shrinking the desktop collage.

The final wording can be reviewed when the rest of the real content is available.

## Analytics Intent

Use Cloudflare Web Analytics to answer:

- Is anyone visiting the website?
- Which Journal entries are being opened?
- Which project pages are being discovered?
- Where are visitors arriving from?

For V1, page views indicate that a page was opened, not that a visitor finished
reading it. Do not add invasive tracking or a custom analytics dashboard.
